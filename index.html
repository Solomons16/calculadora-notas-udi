Calculadora de notas

Cómo se usa

  1. Escribe cada nota entre 0 y 5. Puedes usar punto o coma (3.5 o 3,5).
  2. Si todavía no tienes una nota, déjala en blanco.
  3. Presiona el botón Calcular (o la tecla Enter).
  4. Con los cortes 1 y 2 completos, la calculadora te dice cuánto necesitas en el corte 3 para pasar.

La nota mínima definitiva para aprobar es 3.0
